Optimisation SEO & Performance
Ce dépôt respecte les standards du Web moderne pour garantir une visibilité maximale :
- SEO On-Page : Balises META OpenGraph (LinkedIn/FB) et hiérarchie de titres (H1-H3).
- Accessibilité : Attributs `alt` descriptifs sur l'ensemble des médias.
- Indexation: Présence d'un fichier `robots.txt` optimisé pour les moteurs de recherche.
- WebPerf : Assets compressés (Vidéos < 2Mo, Images < 200Ko) pour un score Lighthouse optimal.
